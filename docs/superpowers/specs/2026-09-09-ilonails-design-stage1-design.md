# Ilonails: дизайн-концепция, этап 1

Дата: 2026-09-09. Проект: сайт студии подологии Ilonails (Минск), клиент Pirus Agency.
Основание: ТЗ (приложение к договору), Google Doc `1ojAa0Z8dvZbAWirfMGamw9faiOfYeb6C-UEIn3Pm9Tg`, этап «Дизайн-концепция» из §08.

## 1. Цель этапа

Собрать кликабельный HTML-прототип двух страниц в мобильной и десктопной версии, показать Илоне, собрать раунд правок №1. После утверждения шаблон страницы услуги тиражируется на остальные 7 страниц проблем, а главная и дизайн-система становятся основой темы WordPress.

Результат этапа: ссылка на GitHub Pages с тремя страницами и этот документ.

## 2. Что решено

| Решение | Выбор | Почему |
|---|---|---|
| Стиль | Из концепта, предварительно согласованного клиентом по главной (PDF `IloNailsstranicysayta.pdf`) | Клиент видел только главную и утвердил её как стиль, не как структуру |
| Первый экран главной | Вариант E «Кружок с Илоной»: светлый экран, заголовок слева, круглое видео Илоны справа, под ним список проблем | Отвечает на вопросы ТЗ «кто за этим стоит» и «кто ко мне прикоснётся» прямо на первом экране; проблемы видны без прокрутки |
| Запасной первый экран | Вариант A: фото кабинета на весь экран, заголовок поверх | Ближе всего к тому, что Илона уже видела |
| Объём | Главная (E), главная запасная (A), страница «Вросший ноготь» | Этап «Дизайн-концепция» в ТЗ: главная плюс типовая страница услуги |
| Формат | Статический HTML и CSS без сборщика, GitHub Pages | Та же вёрстка переносится в тему WordPress, этап вёрстки короче |
| Мобильная версия | Проектируется первой, точки 390 / 768 / 1440 | §04 ТЗ, трафик из Instagram |

Артефакт с вариантами A–E: https://claude.ai/code/artifact/b07763d7-d364-47cf-a5ec-65dedf71ffb2

## 3. Структура прототипа

```
ilonails-prototype/
  index.html            главная, первый экран E
  index-a.html          главная, первый экран A (всё остальное идентично)
  vrosshiy-nogot.html   страница проблемы, шаблон для страниц 2–9 ТЗ
  css/tokens.css        цвета, шрифты, отступы, радиусы
  css/base.css          сброс, типографика, сетка
  css/components.css    кнопки, плитки, строки, карточки, панели
  css/pages.css         специфичное для главной и страницы проблемы
  js/site.js            меню, модальное окно видео, липкая панель
  img/                  фото студии, до/после, специалисты, постеры
  video/                bubble.mp4 (93 КБ), loop.mp4 (325 КБ), full.mp4 (до 15 МБ)
  docs/superpowers/     спека и план
```

Полный ролик Илоны (67 с, 126 МБ в оригинале) пережимается до 1080×1920, H.264, целевой размер до 15 МБ, и кладётся в `video/full.mp4`. Он загружается только по клику на кружок, на первый экран не влияет. На боевом сайте файл ляжет на хостинг WordPress.

## 6. Дизайн-система

Цвета, CSS-переменные `--c-*`:

| Токен | Значение | Роль |
|---|---|---|
| `--c-bg` | #fcfcfb | фон страницы |
| `--c-bg-alt` | #f5f3ee | подложки блоков, подвал |
| `--c-line` | #eceae4 | линии, рамки плиток |
| `--c-ink` | #191b1e | текст, чёрная кнопка |
| `--c-muted` | #5b5a58 | второстепенный текст, контраст с фоном 6,4:1 |
| `--c-accent` | #1e6fa8 | ссылки, точки в строке доказательств, метки; из неона вывески, затемнён до контраста 4,5:1 на #fcfcfb |
| `--c-accent-ink` | #ffffff | текст на акценте |

Шрифты: Cormorant Garamond 500 для заголовков и названий в плитках, Golos Text 400/500/600 для текста и интерфейса. Оба с Google Fonts, `display=swap`, у обоих системный запасной стек.

Шкала заголовков: H1 40 px на 390 и 64 px на 1440, H2 28 / 40, название в плитке 21–22. Текст 15–16 px, строка 1,5. Длина строки текста 45–75 знаков, потолок 80.

Отступы кратны 8. Радиусы: кнопки 999 px, карточки фото 18 px, плитки без радиуса. Тени только у липкой панели и модального окна.

Компоненты: кнопка (тёмная, светлая, контурная, малая), плитка проблемы, строка списка проблем, карточка цены, карточка специалиста, строка доказательств, блок записи, липкая панель, шапка, подвал, модальное окно видео.

Тёмной темы у сайта нет, это осознанный выбор: премиальный светлый интерьер студии и есть бренд.

## 7. Видео

- `bubble.mp4`: квадратная обрезка первых 8 секунд ролика, Илона под неоновой вывеской, без звука, 420×420, 93 КБ. Постер `poster_bubble.jpg`. Автозапуск, без звука, луп, `playsinline`
- `loop.mp4`: отрезок 34,2–41,8 с без субтитров, панорама от вывески к ресепшену, 540×960, 325 КБ. Используется в `index-a.html` вместо фото по желанию клиента, по умолчанию в A стоит фото
- Клик по кружку открывает модальное окно с полным роликом со звуком из `video/full.mp4`, `preload="none"`
- При `prefers-reduced-motion: reduce` видео не запускается, показывается постер
- На странице одновременно не больше одного автозапускаемого видео

Ограничение: ролик снят на телефон, на десктопе крупным планом это заметно. Рекомендация клиенту: при профессиональной съёмке снять отдельный 10-секундный дубль «приветствие в камеру» без субтитров с запасом по краям под круг. Фраза «вас сто процентов пугает неизвестность» из ролика на страницу текстом не выносится (§09 ТЗ).

## 8. Словарь и запреты (§03, §09 ТЗ)

Используем: клиенты, обрабатываем, безопасность, стерильность, подолог, динамика, курс, уход, стопа.
Не используем: пациент, удаляем, удаление, лечение, гости, гостья, лучший, качественный, надёжный, «гарантия результата», «100% клиентов возвращаются», «первые и единственные», числа без источника.

Концепт из PDF содержит «гостей», «гостья», рейтинг «5,0 и 141 отзыв» без выгрузки. В прототип это не переносится.

## 10. Проверка перед показом Илоне

Прогоняется целиком по трём страницам, каждый пункт «да» с указанием места:

- На 390 нет горизонтальной прокрутки
- Контраст текста ≥ 4,5:1, крупного и элементов интерфейса ≥ 3:1
- Кликабельные элементы ≥ 24×24 px
- Длина строки текста 45–75 знаков, не более 80
- При межстрочном интервале 1,5 ничего не ломается
- У всех изображений осмысленный alt
- Поиск по HTML не находит слов: пациент, удаление, удаляем, лечение, гости, гостья
- Липкая панель на 390 не перекрывает содержимое и последний блок
- Видео в кружке запускается без звука, модальное окно открывается и закрывается
- Все ссылки шапки, плиток и смежных проблем ведут на существующую страницу или на явную заглушку `#`
- Lighthouse на профиле 4G: LCP главной ≤ 2,5 с
